# لوحة موازنة علام 2026

لوحة تفاعلية (عربي، من اليمين لليسار) مبنية على ملف الموازنة المنظّف لشركة "علام للتوريدات الغذائية". صفحة HTML واحدة بدون خادم.

## الأقسام
- **العملاء:** رصيد كل عميل مقابل حده الائتماني، مع تصفية بالفئة وبحث وترتيب، وتفاصيل العميل عند الضغط على صفه.
- **الفعلي والموازنة:** المبيعات والمشتريات والمصروفات شهراً بشهر مقابل الموازنة.
- **جودة البيانات:** التنبيهات المتبقية في الملف مرتبة حسب أثرها على الأرقام.

## الملفات
- `dist/index.html` : اللوحة جاهزة، افتحها في أي متصفح.
- `src/template.html` : الكود (HTML و CSS و JavaScript).
- `src/data.json` : البيانات المستخرجة من `allam_budget_2026_clean.xlsx`.
- `build.py` : يدمج البيانات في القالب لإنتاج `dist/index.html`.

## إعادة البناء
```bash
python build.py
```
لتحديث الأرقام بعد رد العميل: أعد تصدير `src/data.json` من الملف المنظّف بنفس البنية، ثم شغّل `build.py`.

## ملاحظات
- التصنيف الائتماني: أخضر أقل من 80% من الحد، أصفر من 80% إلى 100% أو بلا حد، أحمر أكثر من الحد.
- التحصيلات غير المنسوبة لعميل والفواتير بلا تاريخ تظهر في «كل البيانات» فقط.
- الخط Cairo من Google Fonts، وبدونه يستخدم خط النظام.

> البيانات سرية، والمستودع خاص. مشروع التنظيف: `allam-budget-cleaning-2026`.
